# API

API предоставляет доступ к функциям рекомендательной системы фильмов.

## Основные операции

- `POST /recommendations` - сформировать персональные рекомендации;
- `GET /recommendations/{userId}` - получить последние рекомендации пользователя;
- `GET /movies/{movieId}` - получить карточку фильма.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
