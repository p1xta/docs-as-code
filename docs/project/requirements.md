# Требования

## User Stories

### US-01. Получение персональных рекомендаций

Как зритель, я хочу получать список фильмов, подобранных под мои интересы, чтобы не тратить время на самостоятельный поиск.

Критерии приёмки:

- на главной странице отображается список из 10 рекомендованных фильмов.
- в списке нет фильмов, которые пользователь уже оценил.
- если рекомендации сформировать не удалось, показываются популярные фильмы.

### US-02. Оценка фильма

Как зритель, я хочу ставить оценку просмотренному фильму, чтобы рекомендации учитывали мои вкусы.

Критерии приёмки:

- пользователь может поставить фильму оценку от 1 до 10.
- поставленная оценка сохраняется и отображается в карточке фильма.
- после новой оценки список рекомендаций обновляется.

### US-03. Выбор любимых жанров

Как новый пользователь, я хочу указать любимые жанры при регистрации, чтобы сразу получать подходящие рекомендации.

Критерии приёмки:

- при регистрации отображается список жанров для выбора.
- пользователь может выбрать один или несколько жанров.
- первые рекомендации содержат фильмы выбранных жанров.

## Use Case

### UC-01. Получение персональных рекомендаций

**Актор:** зритель (пользователь)

**Цель:** получить список фильмов, соответствующих интересам пользователя.

**Предусловие:** пользователь авторизован и оценил хотя бы один фильм
или указал любимые жанры.

**Основной сценарий:**

1. Зритель открывает раздел «Рекомендации».
2. Система передаёт ML-модели идентификатор пользователя, его оценки и любимые жанры.
3. ML-модель формирует список подходящих фильмов.
4. Система исключает из списка фильмы, которые пользователь уже оценил.
5. Зритель видит список рекомендованных фильмов.

**Альтернативный сценарий:**

Если ML-модель недоступна или данных о пользователе недостаточно, система показывает список популярных фильмов и сообщает, что персональные рекомендации появятся после оценки нескольких фильмов.

**Результат:** зритель получил список персональных рекомендаций или список популярных фильмов.
