# Рекомендательная система фильмов

Сервис подбирает фильмы на основе интересов пользователя: его оценок, просмотренных фильмов и любимых жанров. Рекомендации формирует ML-модель, которая учитывает историю оценок пользователя и предпочтения пользователей со схожими вкусами. Новому пользователю без истории сервис предлагает выбрать любимые жанры и показывает популярные фильмы.

Основные пользователи:

- зритель - получает персональные рекомендации;
- администратор каталога - добавляет и обновляет информацию о фильмах.

Основные функции:

- регистрация и указание любимых жанров;
- оценка просмотренных фильмов;
- получение списка персональных рекомендаций;
- просмотр карточки фильма (описание, жанр, год, рейтинг).

## Комплект документации

1. Описание проекта - для всех участников команды и заказчика. Даёт общее представление о целях, пользователях и функциях сервиса.
2. Требования - для аналитиков, разработчиков и тестировщиков. Фиксирует User Stories, Use Case и критерии приёмки, по которым проверяется результат.
3. Архитектура системы - для разработчиков и DevOps-инженеров. Описывает компоненты сервиса и то, как они взаимодействуют между собой.
4. Документация API — для frontend- и backend-разработчиков. Описывает запросы для получения рекомендаций, оценки фильмов и работы с каталогом.
5. Документация ML-модели - для ML-инженеров. Описывает данные, алгоритм рекомендаций, метрики качества и порядок переобучения модели.
6. Руководство пользователя — для пользователей. Объясняет, как зарегистрироваться, оценивать фильмы и получать рекомендации.
